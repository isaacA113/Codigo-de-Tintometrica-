# Codigo-de-Tintometrica-
Sistema mecatrónico con ESP32 para dosificación automatizada de pigmentos en pintura vinílica. Usa bombas peristálticas y temporización concurrente no bloqueante para inyectar 4 colores simultáneamente. Integra modelo matemático de caudal, HMI (LCD I2C y teclado) y relés optoaislados. Optimiza el proceso manual reduciendo tiempos.
